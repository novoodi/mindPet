## 해석 범위

- 이번 점수는 중요/나중에/보관함 분류 정확도가 아닙니다. 기존 대화 400개의 중요도 정답은 여전히 미검토입니다.
- 고정된 한국어 지시문과 선택지 순서로 수행한 첫 기준 실험입니다. 영어 지시문·선택지 순서·추가 학습의 영향은 아직 평가하지 않았습니다.
- 공개 데이터가 모델 사전학습에 사용됐는지는 확인되지 않았습니다.
- 두 자료는 중복 문장이 있어 과제별로 점수를 따로 냈습니다. 400개를 독립적인 400개 고유 문장으로 해석하지 않습니다.
- 3i4K의 억양 의존 유형은 텍스트만으로 의도를 확정하기 어려운 경우를 포함합니다.
- Laya의 입력/선택지 잘림이 없음을 확인했고, 두 모델의 정확도와 macro F1은 별도 라이브러리로 재계산해 일치를 확인했습니다.
- CPU 4스레드, 요청 1개씩 측정했습니다. 모델 로딩은 지연 통계에서 제외했지만 첫 추론은 포함합니다.
- 두 환경의 PyTorch 버전이 다르고 Kev는 최적화 커널 없이 CPU 참조 구현을 사용합니다. GPU·최적화 구현 간 속도 우열을 뜻하지 않습니다.
- 스마트폰 지연·메모리·배터리는 아직 측정하지 않았습니다.

## 기록과 재현

- results/laya_baseline 및 results/kev_baseline: 입력별 예측, 오답, 혼동 행렬, 정확도, macro F1, 지연, 버전 기록.
- protocol.json: 두 모델에 사용한 동일한 질문 및 선택지. 정답은 모델 입력에 포함하지 않았습니다.
- models/*-manifest.json: 모델·기본 모델·소스 커밋 고정 기록.
- requirements-evaluation.lock.txt 및 requirements-kev.lock.txt: 각각의 설치 환경.
- evaluate_laya.py: --backend laya 또는 --backend kev로 실행. 각 모델의 전용 가상환경을 사용합니다.
- 최종 평가를 본 뒤 지시문을 수정하는 실험은 개발 자료에서 수행하고, 이번 시험을 완전히 새 최종 시험처럼 다시 보고하지 않습니다.
