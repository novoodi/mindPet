# 한국어 모델 원인 진단

개발 자료 32문장에 12개 조건을 적용해 모델마다 384회, 총 768회 로컬 추론했습니다.
기존 시험 400개는 재사용하지 않았습니다. 아래는 작은 개발 표본의 탐색 결과이며 최종 성능 평가가 아닙니다.

## 이번 실험의 판단

- 한국어 본문을 전혀 이해하지 못한다는 가설은 지지되지 않습니다. Kev는 영어 지시문·영어 선택지 설명의 이진 과제에서 27/32개, 역순에서 26/32개를 맞혔습니다.
- 지시문만 영어로 바꾼 경우에도 Kev 이진 과제는 22/32에서 26/32로 개선됐습니다. Laya는 지시문만 바꿔서는 개선되지 않았고 선택지 설명까지 영어로 바꿨을 때 개선됐습니다.
- 두 모델 모두 7종 분류에서 순서 민감도가 큽니다. 같은 문장과 선택지 의미를 유지해도 순서를 바꾸면 40.6~62.5%의 답이 바뀌었습니다. 이진 과제는 더 안정적이었습니다.
- 우선 검증할 후보는 Kev + 영어 지시문/설명 + 단순 이진 판단입니다. 이 설정에서도 명령 16개 중 4개를 놓쳤으므로 자동 알림 숨김에는 사용하지 않습니다.
- 다음 단계는 이 설정을 고정하고, 이번에 보지 않은 자료에서 질문 형태의 간접 요청과 실제 메신저 표현까지 확인하는 것입니다. 원 데이터의 문장 유형과 앱의 행동 요청 정의가 다를 수 있어 직접 검토한 라벨이 필요합니다.
- 언어 표현과 과제 설계가 성능에 영향을 준다는 근거이며, 모델 내부 학습의 근본 원인까지 밝혀진 것은 아닙니다.

## 실험 설계

- 3i4K 개발 자료: 명령 16개, 질문 8개, 서술 8개. 난수 시드 20260930.
- 이진 과제는 원본 명령 라벨을 예, 질문·서술을 아니오로 변환한 보조 과제입니다. 실제 알림 중요도 정답이 아닙니다.
- 7종 과제에도 정확히 같은 32문장을 사용했습니다. 이번 표본에는 나머지 4종 정답이 없으므로 전체 7종 벤치마크로 해석하지 않습니다.
- 언어: 한국어 지시문/한국어 설명(한/한), 영어 지시문/한국어 설명(영/한), 영어 지시문/영어 설명(영/영). 본문은 항상 한국어.
- 순서: 선택지 키와 의미를 고정하고 나열 순서만 반대로 바꿨습니다.
- 정답은 추론에 제공하지 않았습니다. 실험 조건과 표본은 첫 실행 전에 고정했습니다.

## 한계와 다음 결정

- 표본 32개에서 1개 차이는 3.125%p입니다. 작은 차이만으로 어느 설정이 우수하다고 결론 내리지 않습니다. summary.json에 조건별 Wilson 95% 구간을 기록했습니다.
- 12개 조건 중 가장 높은 수치는 설정 선택 편향이 있습니다. 선택한 설정은 새 자료로 검증해야 합니다.
- 문장 유형은 원 데이터의 정의를 따릅니다. 질문 형태의 간접 요청 등 실제 앱 요구와 다른 경계 사례는 추가 검토가 필요합니다.
- 같은 발화에 대해 언어 또는 순서만 바꾼 짝지은 비교입니다. 언어 비교에는 지시문 번역 표현 차이도 포함됩니다.
- 이진 과제는 선택지 수, 문구, 목표 정의가 함께 달라지므로 개선되더라도 선택지 개수 하나만의 효과라고 단정하지 않습니다.
- 기본 모델 대비 효과, 학습 데이터 문제, 학습 후 성능은 이번 실험으로 구분하지 못합니다.
- CPU에서 두 모델을 함께 실행했습니다. 처리 시간은 성능 비교 지표로 사용하지 않습니다.
- 원문, 고정 프로토콜, 모델 버전, 예측과 채점 결과는 results/diagnostics_v1에 보관했습니다.
