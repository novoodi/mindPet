# Kev 알림·카톡 재학습: 학습 전 기준 점수 (2026-10-03)

## 평가 세트 (학습에 절대 쓰지 않음)
- 실제 폰 DB(Fold7, 2026-10-02 추출)에서 뽑았다. 원본: `eval/real_chat.json`, `eval/real_notif.json`
- 정답: `eval/build_eval.py`에 직접 적었다. 애매한 18개는 `eval/확인필요.md`
- **실제 카톡 325개**: 나에게 하는 질문 16, 요청 2, 둘 다 아님 307 (카톡 채널 자동 메시지 6개 제외)
- **실제 알림 44개**: 광고·유도 17, 오늘 봐야 함 9

정답 yes가 적어서(카톡 18개, 알림 9~17개) 한두 개 차이로 비율이 크게 흔들린다. 비율보다 개수를 본다.

## 측정 방법
- 모델: `runs/kev-korean-binary-v2-ep2` (지금 앱에 들어간 Kev, PyTorch. 폰 llama.cpp와 64/64 일치 확인됨)
- `python -m kev.benchmark --run ... --data <eval>` → `eval/score.py <rows.json>`
- 판정 기준: yes 확률 0.5 이상
